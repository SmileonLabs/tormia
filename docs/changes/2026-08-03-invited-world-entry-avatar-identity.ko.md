# 초대 월드 입장 아바타 식별자

## 결정

월드 입장은 선택한 월드에 명시적으로 지정된 콘텐츠 패키지를 사용한다.
멤버의 해당 월드 아바타가 없으면 프로젝트 아바타 시드, 월드 ID, 인증된
사용자 ID로 고유 식별자를 계산하여 Authority에 생성을 요청한다. 이미 등록된
아바타 ID는 변경하지 않는다.

## 이유

방문자 계정 기준 콘텐츠 패키지를 검사하면 정상적인 초대 월드도 거절됐다.
또한 씬 시드와 월드 ID만으로 아바타 ID를 만들면 모든 사용자가 소유자의
아바타 ID와 충돌하여 `avatar_owned_by_another_user`가 발생했다.

## 검증

- 같은 월드와 사용자는 항상 같은 식별자를 얻는다.
- 같은 월드의 서로 다른 사용자는 서로 다른 아바타 식별자를 얻는다.
- 초대된 테스트 계정으로 원격 공유 월드 입장을 완료했다.
- 아바타 검증과 생성의 최종 권한은 서버 Authority가 유지한다.
- 읽기 전용 의미 계약 입장 검증은 일시적인 응답 손실 때 동일한 불변 manifest만
  재시도하며, 거절된 계약을 생성·변경하거나 우회하지 않는다.
