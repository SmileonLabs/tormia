## 의도

사람과 AI가 함께 만드는 변경을 반복 가능하게 만들되, 별도의 게임 시스템을 추가하지
않습니다. 하네스는 회귀를 fallback 동작으로 숨기지 않고 드러내야 합니다.

않습니다.

## 결정과 경계

`AGENTS.md`는 프로젝트 규칙을 정의합니다. JSON 시나리오 목록은 핵심 동작의 증거
위치를 지정합니다. PowerShell 스크립트는 환경 계약을 검사하고 Unity 테스트를
실행합니다. 검사 과정에서 월드, 규칙, 프로필, 씬을 변경하지 않습니다.

## 검증

| 경우 | 기대 결과 | 증거 |
| --- | --- | --- |
| 빠른 검증 | 한글/영문 컨텍스트와 시나리오 증거가 유효 | `verify-development.ps1 -SkipServerBuild` 통과 |
| Authority 빌드 | 현재 소스에서 Docker 이미지 빌드 | `docker compose ... build world-authority` 통과 |
| 로컬 서비스 | Authority health endpoint 응답 | `GET /health` -> `healthy` |
| Unity PlayMode 핵심 묶음 | 핵심 시나리오가 단독/함께 통과 | 5 / 5 통과 |
| Unity EditMode 언어팩 | 등록 용어에 언어 항목이 존재 | 1 / 1 통과 |

## 해결한 회귀 기준선

첫 하네스 실행은 기존 실패를 발견했습니다. fallback 동작으로 숨기지 않고 각 책임
계층에서 수정했습니다.

1. 물/근처 관측 센서는 런타임 월드 Reset/복원 직후 일반 관측 주기를 기다리지 않고
   관측 Fact를 다시 발행합니다.
2. 물/부력 테스트는 메인 씬의 지형과 Collider가 물리 검증에 영향을 주지 않는 격리된
   좌표를 사용합니다.
3. 물리 프로필 테스트는 현재 데이터 기반 프로필 계약에 맞게 필요한 부력 규칙 ID를
   제공합니다.
4. `skill_grant_requires_rule`의 영문/한글 Fact 템플릿을 언어팩에 등록했습니다.
