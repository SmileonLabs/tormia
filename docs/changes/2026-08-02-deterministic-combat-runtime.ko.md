# 결정적인 전투 런타임 복구

## 문제

불변 액션 정의의 새 버전을 발행한 뒤 과거 발행 버전까지 자율 액터 SQL에
결합되어 몬스터 하나가 여러 후보로 증식했다. 모호성 안전장치가 모든 후보를
제외하여 추적·접촉 피해가 중단됐다. 죽은 표현 객체의 일부 충돌체와 만료된
이동 Intent의 pose 관찰도 입력·접촉 증거를 방해했다.

## 결정

- 활성 패키지 안에서 액션별 가장 높은 발행 정의 버전 하나만 선택한다.
- 여러 활성 패키지가 같은 액터의 완전한 계약을 제공할 때만 모호성으로 닫는다.
- 죽은 대상은 모든 소유 충돌체와 포인터 후보에서 제외한다.
- 장착 표시는 Authority 장착 관계와 활성 장착/해제 액션만 따른다.
- 충돌 해결 pose는 활성 이동 Intent가 있을 때만 전송한다.

## 검증

서버 단위 테스트, Unity 전투·이동 EditMode 테스트, 개발 하네스 및 실제 월드의
장착·플레이어 공격·몬스터 접촉 피해 루프로 검증한다. Rule Block 또는 필수
생명주기 계약을 제거한 경로는 동작하지 않아야 한다.
## 후속 보완: 최신 플레이어 접촉 증거

자율 근접 공격은 Authority 이동 접촉뿐 아니라 최신 충돌 해결 위치
관찰도 접촉을 확인해야 플레이어 피해를 확정한다. 정지 중에도 0 입력
이동 lease를 갱신하여 Unity에 위치 권한을 넘기지 않으면서 관찰을 최신
상태로 유지한다.
플레이어 이동 설정 조회도 활성 패키지별 최신 locomotion Action 발행
버전 하나로 불변 이력을 축약한다.
