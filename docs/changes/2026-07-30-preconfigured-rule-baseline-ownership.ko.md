# 기본 설정 규칙 블록의 의미 기준 패키지 소유

## 요약

- **날짜:** 2026-07-30
- **상태:** 구현 및 검증 완료
- **범위:** World Authority 의미 패키지, 카탈로그 배치 마이그레이션,
  런타임 규칙 블록 제거

## 의도

배치 정의에 처음부터 들어 있던 규칙 블록도 빠른 설정으로 적용한 규칙과
동일한 계약을 따라야 합니다. 어느 쪽이든 규칙을 제거하면 그 규칙을
가능하게 만든 전체 의미 기여분이 함께 제거되어야 하며, 숨은 트리플·물리
의미·Unity fallback이 남으면 안 됩니다.

## 결정과 경계

- 카탈로그 기본 동작은 `OntologyPlaceableDefinition` 데이터에서 생성되는
  `template_semantic_baseline` 의미 패키지로 표현합니다.
- 패키지는 정의의 초기 개념·Fact, 물리·부착 프로필 선언, 현재 활성 상태인
  기본 규칙 블록을 포함합니다.
- Authority는 다른 활성 패키지가 소유하지 않은 정확히 일치하는 기존
  Fact와 바인딩만 인수할 수 있습니다. 템플릿·프리팹·메시·오브젝트명
  예외는 없습니다.
- 미소유 레거시 바인딩이 요청 규칙·매개변수와 같고 불변 정의 버전만
  이전 버전이면, Authority는 동일 리비전에서 그 바인딩과 추론 결과를
  철회하고 새 바인딩 ID로 요청 버전을 삽입합니다.
- 기존 배치 엔티티는 의미 계약 버전 상승을 통해 한 번만 마이그레이션합니다.
  이미 제거된 기본 규칙은 인수하거나 다시 만들지 않습니다.
- 소유 규칙 블록 하나를 제거하면 동일한 Authority 리비전에서 패키지
  기여분 전체가 제거됩니다. 독립적으로 작성한 데이터는 보존됩니다.

## 검증

| 경우 | 기대 결과 | 증거 |
| --- | --- | --- |
| 활성 | 신규 또는 마이그레이션된 기본 엔티티의 활성 기본 계약을 Authority 의미 패키지 하나가 소유합니다. | `BaselinePackageCanRequestUnclaimedContributionAdoption`, 의미 패키지 Authority 스모크 |
| 버전 마이그레이션 | 미소유 이전 규칙 블록 버전을 철회하고 새 불변 ID를 가진 요청 버전 하나만 활성 상태로 둡니다. | 의미 패키지 Authority 버전 마이그레이션 스모크 |
| 제거 | 소유 바인딩 하나를 제거하면 형제는 유지하고, 마지막 바인딩 제거 시 기준 패키지 소유 트리플·프로필을 철회합니다. | `RemovingPreconfiguredRulesCompletesOwnedBaselineOnlyAtLastRule`, 의미 패키지 Authority 스모크 |
| 보존 | 독립 작성 개념·Fact 또는 다른 활성 패키지 소유 행은 인수하거나 제거하지 않습니다. | PlayMode 독립 데이터 단언, Authority 인수 쿼리 |

## 성능과 멀티플레이 영향

마이그레이션은 대상 엔티티마다 한 번 실행되는 리비전 기반 Authority
명령입니다. 제거는 하나의 원자적 Authority 트랜잭션입니다. 폴링, 프레임별
영속 쓰기, Unity 소유 게임플레이 평가는 추가하지 않습니다.
