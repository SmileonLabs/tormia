# 입력·월드 편집·온톨로지 애니메이션 수정

## 요약

- **날짜:** 2026-07-21
- **상태:** 구현 및 검증 완료
- **범위:** Unity 표현/입력 어댑터와 월드 편집 상호작용

## 결정 사항

1. 런타임 도구막대는 하이라키에 만든 월드 편집 핸들 하나만 사용합니다.
   온톨로지 버튼은 핸들의 대상 오브젝트를 다시 선택한 뒤 기존 편집기를 열며,
   오브젝트를 삭제하거나 교체하지 않습니다.
2. 장착 해제는 온톨로지 상호작용 볼륨과 실제 보이는 렌더러 영역을 모두
   맞혀야 합니다. 큰 프로필 볼륨의 빈 공간을 클릭하는 것만으로 해제되지
   않습니다.
3. 버튼의 이벤트는 하이라키에 있는 Button에 유지하되, 실제 클릭 영역은
   보이는 아이콘 Graphic으로 사용합니다. 따라서 하이라키에서 아이콘을
   옮기면 클릭 영역도 함께 이동합니다.
4. 이동과 애니메이션 입력은 Input System 플레이어 컨트롤러 하나가 담당합니다.
   축 값과 애니메이션을 덮어쓰던 구형 `MovePlayerInput`, `CharacterMover`는
   플레이어에서 비활성화했습니다.
5. 점프는 일시적인 입력 신호이며 `CharacterController`의 수직 속도와
   중력/점프 높이 설정으로 처리합니다. 애니메이션 어댑터는 온톨로지에서
   결정된 결과만 표현하고, 메시나 오브젝트 이름으로 규칙을 만들지 않습니다.

## 검증

| 경우 | 결과 | 근거 |
| --- | --- | --- |
| 선택된 오브젝트에서 온톨로지 아이콘 클릭 | 통과 | `OpenOntologyEditorFor`가 재선택 후 기존 창을 엶 |
| 보이는 장착물 밖을 클릭해 해제 | 통과 | `OntologyAttachmentAdapter.RaycastPresentation` 영역 검사 |
| 좌우/앞뒤 이동 애니메이션 | 통과 | Input System 축이 Animator 파라미터를 갱신하고 구형 입력기를 끔 |
| 중력 포함 점프 | 통과 | `CharacterController` 수직 속도 및 중력 경로 |
| Unity 컴파일 후 콘솔 | 통과 | 테스트 실행 전 오류/경고 0건 |
| 개발 하네스 | 통과 | `verify-development.ps1 -SkipServerBuild` |

전체 EditMode 테스트에는 이번 변경과 무관한 캐릭터 파츠 3건과 부력 의미
검증 2건의 기존 실패가 남아 있습니다. 별도의 데이터/테스트 격리 작업으로
분리해 처리해야 합니다.
