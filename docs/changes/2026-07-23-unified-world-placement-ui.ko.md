# 통합 월드 배치 UI

## 결정

런타임 배치는 `오브젝트`, `NPC`, `몬스터` 모드를 가진 하나의 수정 가능한 TOV 패널을
사용합니다. 카탈로그 모드는 `OntologyPlaceableDefinition.placementKind`가 소유하며,
Unity는 프리팹·메시·오브젝트 이름으로 모드를 추론하지 않습니다.

## 화면 구성

- 상단 모드 탭과 좌측 카테고리 행은 선택·미선택 스프라이트를 별도 자산으로 사용합니다.
- 카테고리와 온톨로지 데이터 영역은 스크롤되며 스크롤바는 표시하지 않습니다.
- 예전 상태 행과 하단 닫기 버튼은 제거했습니다.
- 우상단의 수정 가능한 닫기 아이콘과 `Esc`로 패널을 닫습니다.
- hierarchy는 `ObjectPlacementHUD.prefab`에 작성하고 런타임 코드는 데이터·콜백·선택 상태만
  연결합니다.

## 검증

- 프리팹 구조와 제거된 예전 컨트롤은 `OntologyWorldPlacementUiTests`에서 확인합니다.
- 기존 카탈로그 항목은 기본적으로 `Object`가 되어 저장된 콘텐츠를 유지하고, 이후 NPC와
  몬스터 항목은 명시적으로 작성할 수 있습니다.
