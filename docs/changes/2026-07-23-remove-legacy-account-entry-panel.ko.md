# 예전 통합 계정 진입 패널 제거

## 요약

- **날짜:** 2026-07-23
- **상태:** 구현
- **분류:** Unity 표현 및 계정 진입 화면 이동

## 의도와 경계

가입·입장 흐름은 이제 로그인, 가입, 캐릭터 생성·선택, 월드 생성·선택, 프로필 최종
확인, 월드 입장 로딩의 분리된 패널을 사용합니다. `OntologyAccountEntryPanel`은 이
기능들과 중복되고 현재의 최종 확인·로딩 단계를 우회하는 직접 월드 입장 경로도
남아 있었으므로 활성 씬, 런타임 코드, 화면 이동 테스트에서 완전히 제거합니다.

캐릭터 생성 화면의 뒤로 가기 동작은 다음처럼 명확하게 구분합니다.

- 기존 캐릭터가 하나 이상 있으면 캐릭터 선택으로 돌아갑니다.
- 캐릭터가 없으면 로그아웃한 뒤 로그인으로 돌아갑니다.

이 변경은 Unity 표현과 화면 이동만 바꿉니다. 계정 소유 데이터를 월드 Fact로 옮기지
않으며 새로운 Authority 명령도 추가하지 않습니다.

## 검증

| 경우 | 기대 결과 | 증거 |
| --- | --- | --- |
| 기존 계정 | 캐릭터 생성에서 뒤로 가면 캐릭터 선택으로 이동 | `CharacterCreationBackReturnsExistingAccountToCharacterSelection` |
| 빈 계정 | 뒤로 가면 로그아웃하고 로그인으로 이동 | `CharacterCreationBackSignsOutEmptyAccountAndReturnsToLogin` |
| 제거된 동작 | 활성 씬 오브젝트, 컴포넌트, Navigator 필드와 경로에 통합 패널 참조가 없음 | 씬·컴포넌트 검색 및 소스 참조 검사 |
| 회귀 | 현재 계정 화면 이동과 개발 하네스가 정상 통과 | Navigator PlayMode 테스트 4개와 `verify-development.ps1 -RequireServices` |
| 하네스 신뢰성 | 결과 파일이 없는 Unity 배치 실행을 통과로 잘못 보고하지 않음 | `run-unity-harness-tests.ps1`이 프로세스 종료 코드와 결과 XML을 확인 |

## 성능과 권한 영향

새로운 폴링, 데이터베이스 쓰기, 영속 월드 이벤트, Authority 호출은 추가하지
않았습니다. 캐릭터가 없는 계정의 뒤로 가기는 기존 로그아웃 동작을 사용합니다.
