# TOV 런타임 상태 및 캐릭터 알림 UI

## 범위

- 기존 기술 디버그 문자열 HUD를 이동, 상호작용 대상, 월드 권한,
  저장·동기화 상태의 네 개 행으로 구성된 편집 가능한 카드로 교체했다.
- 캐릭터 Fact 토스트를 카드, 강조선, 아이콘, 제목, 보조문구, 말풍선
  포인터가 각각 분리된 하이라키로 다시 구성했다.
- `Assets/Art/UI/RuntimeStatusIcons`에 프로젝트 소유 아이콘 PNG 8종을
  추가했다.

## 데이터 소유권과 권한

이 변경은 Unity 표현 계층 변경이다. HUD는 기존 런타임 입력, 온톨로지
Fact, World Authority 클라이언트 상태만 읽는다. 영구 Fact를 만들거나
게임 규칙을 추론하지 않으며 World Authority API를 우회하지 않는다.

## 켜진 경우와 제거된 경우

- 켜진 경우: 활성 게임 Canvas에 네 개 상태 값이 표시되고, 캐릭터 Fact
  변경 알림은 심각도 아이콘·제목·선택적 보조문구로 표시된다.
- 제거된 경우: HUD에서 큰 기술 디버그 Fact 덤프를 표시하지 않는다.
  기존 단일 문자열 토스트 호출은 계속 지원하며, 가능한 경우 첫 번째
  콜론을 기준으로 제목과 보조문구를 나눈다.

## 저작과 검증

`Tormia/UI/Apply TOV Runtime Status & Toast Design` 메뉴로 편집 가능한
하이라키를 복구하거나 다시 생성할 수 있다. Tormia 메인 씬 스모크
테스트에서 상태 행과 토스트 레이어 구성을 검증한다.
