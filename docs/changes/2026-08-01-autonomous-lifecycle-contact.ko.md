# 자율 행위자 생명주기와 근접 접촉

## 결정

자율 전투의 실행 가능 여부는 현재 Authority의 생존 투영으로 제한하고,
근접 접촉은 넓은 중심 거리 행동 범위가 아니라 작성된 캡슐 충돌 의미로
판정합니다.

## 생산 경로

`생명/충돌 트리플 -> 배정된 공격 Rule Block -> Authority 발생 미리 평가 ->
작성된 캡슐 접촉 -> 규칙 평가 -> 영속 피해 또는 사망 -> 임시 생명주기 상태
즉시 폐기 -> Unity 표현`

## 검증 근거

- 충돌 의미가 없거나 떨어져 있으면 실패로 닫힙니다.
- 현재 생존 투영에서 빠진 캐시 행위자를 즉시 폐기합니다.
- 피해 전에 Rule Block과 현재 실시간 위치·접촉을 다시 확인합니다.
- 서버 회귀 테스트와 개발 하네스가 활성 및 제거 경로를 함께 검증합니다.
- 의미 기준선 업그레이드에서 가변 체력·생존 상태를 제외하고, 기존 충돌 값은
  사망 엔티티를 부활시키지 않는 방향으로 정규화합니다.
