# 패키지 버전을 넘는 canonical 규칙 해석

- 날짜: 2026-08-03
- 상태: 구현 및 검증

## 결정

발행된 규칙 정의는 규칙 ID와 정의 버전으로 식별되는 전역 불변 콘텐츠입니다.
Authority 액션은 월드의 활성 규칙 바인딩을 이 canonical 발행 정의에 직접
연결합니다. 규칙이 처음 발행된 패키지 버전과 현재 월드 패키지 버전이 같을
필요는 없습니다.

## 이유

콘텐츠 게시기는 동일한 규칙 ID/버전을 이후 패키지 릴리스에서 재사용합니다.
실행 경로만 패키지 버전 일치를 요구해 유효한 바인딩이 Projection에는 보이지만
실행되지 않는 문제가 발생했습니다.

## 검증

- 서버 빌드 및 단위 테스트
- 규칙 바인딩 제거 시 기존처럼 fail-closed
- 패키지 업그레이드 후 `EquipItemOnInteractionIntent@1` 장착 실행
