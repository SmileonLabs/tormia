# 수정 가능한 TOV 캐릭터 생성 UI

## 요약

- **날짜:** 2026-07-23
- **상태:** 구현 및 런타임 검증 완료
- **데이터 분류:** Unity 표현과 언어팩 표시 문구

## 의도와 경계

계정 캐릭터 생성 화면을 확정한 넓은 TOV 온보딩 디자인으로 변경했습니다.
13개 카테고리 레일, 원형 파츠 그리드, 실시간 미리보기, 이름 입력, 이동 버튼은
기존 씬 및 런타임 어댑터 계약을 그대로 사용합니다. 파츠 선택은 기존 캐릭터
파츠 어댑터를 통해 계정 소유 외형만 변경하며 UI가 별도 게임 규칙이나
온톨로지 규칙을 만들지 않습니다.

모든 시각 계층과 템플릿은 하이라키에서 개별 수정할 수 있습니다. 런타임은
기존 데이터베이스에서 카테고리와 파츠 인스턴스만 채우며 배치 영역의 위치를
덮어쓰지 않습니다.

## 검증

| 경우 | 기대 결과 | 증거 |
| --- | --- | --- |
| 활성화 | TOV 프레임·로고·카테고리·원형 썸네일·큰 미리보기·이름 입력·버튼이 표시됨 | `character_creation_tov_editable_runtime_final.png` |
| 카테고리 | 13개 카테고리가 스크롤바 없이 세로 레일에 생성됨 | 런타임 하이라키에서 canonical 카테고리 버튼 13개 확인 |
| 파츠 선택 | 썸네일 클릭 즉시 선택 파츠를 장착 또는 해제함 | 런타임 클릭 결과 `해제함: 남성 헤어 001` |
| 화면 이동 | 뒤로 가면 생성·외형 계층이 모두 닫히고 다시 열면 모두 복구됨 | 런타임 `creation=0, appearance=0`, 복귀 후 `1/1` |
| 에디터 미리보기 | 배치를 다시 생성하지 않고 캐릭터 화면만 격리해서 볼 수 있음 | `Tormia/UI/Preview/Character Creation Panel`, 카테고리 8개·파츠 16개 더미 오브젝트 배치 |
| 이전 동작 제거 | 임베디드 화면에서 별도 장착·해제 상세 버튼은 계속 숨김 | 썸네일 선택만 외형 변경 동작으로 사용 |
| 회귀 | Unity 테스트와 개발 하네스가 정상임 | EditMode 53/53, PlayMode 34/34, World Authority Docker 빌드를 포함한 `verify-development.ps1` 통과 |

## 성능과 권한 영향

기존 파츠 선택 호출을 제외하면 표현 계층 변경입니다. polling, 영속 월드 이벤트,
프레임별 DB 쓰기, 실시간 통신, Authority 규칙은 추가하지 않았습니다.
