# 정규화된 애니메이션 전환

## 요약

- **날짜:** 2026-07-29
- **담당:** 프로젝트 소유자와 Codex
- **상태:** 구현 및 검증
- **범위:** Unity 온톨로지 애니메이션 표현

## 의도

온톨로지 Idle 애니메이션 클립에서 걷기로 바뀔 때 첫발에서 아바타가 아래로
꺼져 보이던 현상을 제거합니다.

## 데이터 분류

- Unity 표현
- 일시적 애니메이션 상태

계정 프로필, 지속 월드 Fact, 추론, Rule Block, 행동 권한, 물리 프로필은
추가하거나 변경하지 않습니다.

## 원인과 결정

재현 중 플레이어 루트 Transform과 `CharacterController`는 지지면 높이를
그대로 유지했습니다. 골반과 발만 Idle에서 Walk로 블렌딩되는 동안
내려갔습니다.

기존 어댑터는 나가는 전신 클립과 들어오는 전신 클립을 서로 다른
`AnimationLayerMixerPlayable` override 레이어에 두고 보완 가중치를
적용했습니다. override 레이어는 순차적으로 합성되며 정규화된 클립
크로스페이드가 아닙니다. 전환 중간에 컨트롤러 또는 바인드 포즈가 섞이면서
아바타 높이가 낮아졌습니다.

이제 어댑터는 완전히 가중된 온톨로지 표현 레이어 하나를 유지합니다. 그
레이어 내부의 정규화된 2입력 `AnimationMixerPlayable`이 클립 간
크로스페이드를 담당합니다. 컨트롤러와 클립 사이의 전환만 바깥 레이어
경계에서 가중치를 바꿉니다.

## 온톨로지 경계

Triple, 할당된 Rule Block, Authority 행동 결과, canonical 애니메이션 의도,
액터 레퍼토리가 계속 행동과 클립의 사용 가능 여부를 결정합니다. 믹서는
이미 선택된 클립을 표현할 뿐이며 온톨로지 계약이 없을 때 fallback을
제공하지 않습니다.
