# Authority 전투와 표현 경계

## 요약

- **날짜:** 2026-07-28
- **상태:** 구현 및 검증
- **범위:** Unity 입력·타깃, World Authority 전투, 애니메이션, 장착,
  월드 입장 표현

## 의도

무기·몬스터·애니메이션을 추가할 때마다 Unity 예외를 추가하지 않아도 되도록
공격 구조를 반복 가능한 생산 라인으로 만듭니다. Unity에서는 후보 선택의
반응성을 유지하되 게임플레이 승인과 영속 효과는 World Authority만 소유합니다.

## 데이터 분류

- 영속 월드 데이터: 장착 관계, 체력, 생존 상태, 드롭 상태
- 일시 관찰: 포인터 후보, 로컬 충돌 지면 정착, 이동
- Unity 표현: 애니메이션, VFX, 장착 자세
- Authority: 행동 패키지 버전, 조건, 거리, 피해, 변경

## 결정과 경계

- 작성된 `Player/Attack` 행동은 카메라 시점 고정 입력과 분리합니다.
- Unity는 배우·후보 대상·장착 도구·불변 행동 식별자만 전송합니다. 적대성·거리·
  피해·사망을 중복 판정하지 않습니다.
- 승인된 행동의 canonical 애니메이션 의도만 배우 레퍼토리로 해석합니다.
  거절되거나 불완전한 행동에는 공격 fallback 클립이 없습니다.
- 필수 무기 손잡이 메타데이터는 프리팹이 소유합니다. 누락되면 배우 루트에
  붙이는 대신 장착 표현을 비활성화합니다.
- 입장 지면 정착은 입력 전 한 번 수행하는 제한된 충돌 표현입니다. 영속 Fact나
  체크포인트 재작성으로 바꾸지 않습니다.

## 활성·제거 경우

| 경우 | 기대 결과 |
| --- | --- |
| 작성된 공격 입력이 투영 엔티티를 선택 | Authority가 정확한 버전 행동 평가 |
| 대상이 거리 밖이거나 적대적이지 않음 | 피해·공격 표현 없이 Authority 거절 |
| 승인 행동 의도가 배우 레퍼토리에 있음 | 승인된 일시 애니메이션 재생 |
| 애니메이션 의도 또는 레퍼토리 제거 | fallback 없이 진단 단계 기록 |
| 필수 보정 손잡이 기준점 존재 | 무기 자체 손잡이를 배우 소켓에 정렬 |
| 필수 손잡이 또는 배우 소켓 제거 | 장착 표현 비활성화 |
| 일반 첫 입장 | 입력 전에 아바타를 한 번 지면에 정착 |
| 수영·탑승 중 입장 | 지면 정착 생략 |

## 검증

- Unity EditMode 전투·애니메이션 생산 라인·의미 검증 테스트
- Unity PlayMode 장착 활성·제거 테스트
- World Authority 행동 평가·런타임 거리 단위 테스트
- 개발 하네스 매니페스트, 서버 빌드, Unity Console
