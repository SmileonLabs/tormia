# 편집 가능한 TOV 퀘스트·행동 UI

## 요약

- **날짜:** 2026-07-23
- **상태:** 구현
- **분류:** Unity 표현

## 의도와 경계

`QuestActionPanel`이 생성된 퀘스트와 현재 가능한 온톨로지 행동을 승인된 TOV 시각
스타일로 표시합니다. 메인 패널, 제목, 스크롤 영역, 선택 퀘스트 요약, 퀘스트 카드
템플릿, 행동 버튼 템플릿, 하단 안내, 닫기 버튼과 외부 열기 버튼을 각각의 uGUI
하이라이키 오브젝트로 저작해 Unity Editor에서 직접 조정할 수 있습니다.

Play Mode에 들어가지 않아도 최종 배치를 볼 수 있도록 에디터 전용 샘플 행을
배치했습니다. `OntologyQuestActionPanel`은 `Awake`에서 샘플을 비활성화하고 실제
런타임 데이터에는 숨겨진 저작 템플릿만 복제합니다.

이 변경은 퀘스트, 행동 후보, 규칙 또는 Fact를 만들지 않습니다. Unity는 계속
온톨로지 런타임 또는 World Authority가 반환한 결과만 표현합니다.

## 검증

| 경우 | 기대 결과 | 증거 |
| --- | --- | --- |
| 에디터 저작 | 주요 시각 요소를 하이라이키에서 각각 수정 가능 | `quest_action_tov_editable_final_verified.png` |
| 런타임 데이터 | 실제 퀘스트·행동 행은 숨겨진 저작 템플릿에서 복제 | `OntologyQuestActionPanel` |
| 제거된 미리보기 동작 | 에디터 샘플 행은 Play Mode에서 비활성 | `TormiaMainSceneSmokeTests` |
| 언어팩 | 새 구역 제목, 안내, 미선택 문구가 영어·한국어로 표시 | 언어팩 CSV 항목 |

## 성능과 권한 영향

기존과 같이 새로고침할 때만 목록 행을 다시 만듭니다. 프레임별 Authority 요청,
영속 월드 쓰기 또는 새로운 게임플레이 우회 처리는 추가하지 않았습니다.
# 정렬 보완

- 상단은 다른 TOV 계정 패널과 같은 로고·중앙 제목·부제·독립 닫기 버튼 구조로 통일했습니다.
- 퀘스트 카드의 진행 게이지와 상태 버튼 영역을 분리해 서로 겹치지 않게 했습니다.
- 실행 중 진행률은 임시 수치가 아니라 완료된 퀘스트 목표 비율로 계산하며, 상세 퍼센트도 같은 값을 사용합니다.
