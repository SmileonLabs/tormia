- **날짜:** 2026-07-26
- **담당:** TOV 팀
- **상태:** 구현 및 검증 완료
- **관련 요청:** 저장소와 기술 계약을 바꾸지 않고 제품명을 TOV로 확정

## 의도

안정적인 구현·데이터 식별자를 대규모로 변경하지 않으면서 Unity 빌드와
사용자용 프로젝트 문서에 하나의 TOV 브랜드를 표시합니다.

## 결정과 경계

Unity 제품명은 `TOV`, 회사명은 `Smileon Labs`, application identifier는
`com.smileonlabs.tov`를 사용합니다. 사용자용 문서와 하네스 출력도 TOV를
사용합니다.

`tormia` 폴더, `Tormia.*` 네임스페이스/어셈블리, 씬·스크립트 경로, Docker
자원, API·저장소 prefix, DB 식별자, canonical 온톨로지 ID는 유지합니다.
숨겨진 호환 별칭이나 중복 데이터 소유자를 추가하지 않습니다.

## 온톨로지 표현

온톨로지 용어, Fact, 프로필, 규칙, 규칙 블록, 패키지 식별자는 바뀌지
않습니다. TOV는 제품 및 표현 라벨일 뿐입니다.

## 검증

| 경우 | 기대 결과 | 증거 |
| --- | --- | --- |
| 활성 / 추가 | Unity와 프로젝트 사용자 문서가 TOV를 표시 | `ProjectSettings/ProjectSettings.asset`, `README.md` |
| 비활성 / 제거 | 안정적인 `Tormia.*` 및 영속 ID를 치환하지 않음 | 저장소 식별자 감사 |
| 회귀 / 예외 | 새 로그인 후 기존 Authority 계정·월드 상태를 이어서 사용 | 계정/월드 재접속 스모크 |

## 성능과 멀티플레이 영향

런타임 폴링이나 네트워크 프로토콜 변경은 없습니다. 제품명/회사명 변경으로
일부 플랫폼에서 새 Unity 로컬 설정·저장 범위를 사용하므로 인증 정보는
마이그레이션하지 않고 한 번 다시 로그인해야 할 수 있습니다. Authority 영속
데이터는 그대로 유지됩니다.
