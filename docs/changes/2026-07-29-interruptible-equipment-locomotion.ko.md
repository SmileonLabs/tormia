# 중단 가능한 장착-이동 전환

## 요약

- **날짜:** 2026-07-29
- **담당:** Unity 온톨로지 애니메이션 표현
- **상태:** 구현
- **관찰 문제:** 무기 장착 직후 이동하면 아바타 위치만 움직이고 장착 자세가
  유지되었습니다. 한 번 멈춘 뒤 다시 이동해야 `WeaponWalk`이 재생되었습니다.

## 원인

`WeaponEquip`과 `WeaponUnequip`이 중단 불가로 작성되어 있었고, 애니메이션
어댑터는 일시적 행동 표현이 활성화된 동안 이동 관측을 무시했습니다. 장착
상태와 이동은 정상이며 표현 스케줄링이 전환을 막고 있었습니다.

## 결정

중단 정책은 계속 애니메이션 매니페스트가 소유합니다. 일시적 표현은 해당
정의가 중단 가능하고 이동이 관측될 때만 현재 이동 의도에 양보합니다. 장착과
해제 표현은 중단 가능으로 작성합니다. 공격과 피격 표현은 자신의 매니페스트
항목이 명시적으로 바뀌지 않는 한 중단 불가를 유지합니다.

이 변경은 게임플레이 Fact를 만들지 않으며 무기·프리팹·메시·오브젝트명
예외를 추가하지 않습니다.

## 검증

| 경우 | 기대 결과 | 증거 |
| --- | --- | --- |
| 중단 가능한 장착 + 이동 | 카탈로그가 선택한 `WeaponWalk`으로 즉시 전환 | `EquipmentTransitionMetadataAllowsImmediateLocomotion` |
| 중단 불가 표현 + 이동 | 작성된 표현 잠금 유지 | `EquipmentTransitionMetadataAllowsImmediateLocomotion` |
| 장착 상태 | Authority 소유 `equipped_by` 변화 없음 | 기존 Authority 장착 테스트 |
