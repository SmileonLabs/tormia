# 수정 가능한 TOV 계정 생성 UI

## 요약

- **날짜:** 2026-07-23
- **상태:** 구현 및 런타임 검증 완료
- **데이터 분류:** Unity 표현과 언어팩 표시 문구

## 의도와 경계

실제 가입 패널을 확정한 TOV 로그인 디자인과 같은 체계로 변경했습니다.
로고, 테두리, 카드, 라벨, 입력창, 버튼 표면은 각각 씬에 저장된 uGUI
오브젝트이므로 직접 후보정할 수 있습니다. 가입은 기존 World Authority 흐름을
그대로 사용하며 계정 데이터를 월드 Fact로 옮기지 않습니다. 런타임 코드는
문구와 상호작용 상태만 갱신하고 배치는 소유하지 않습니다.

## 검증

| 경우 | 기대 결과 | 증거 |
| --- | --- | --- |
| 활성화 | 이메일·표시 이름·비밀번호가 TOV 카드에 표시됨 | `account_creation_tov_editable_runtime.png` |
| 언어팩 | 세 입력 안내 문구가 현재 언어로 표시됨 | 런타임에서 `name@example.com`, `게임에서 사용할 이름`, `10자 이상의 비밀번호` 확인 |
| 화면 이동 | 뒤로 버튼이 가입 동작을 바꾸지 않고 로그인으로 이동함 | 런타임 `creation=0, login=1`, 다시 열었을 때 `creation=1` |
| 후보정 가능 | 시각 요소를 각각 선택할 수 있음 | 프레임·표면·로고·라벨·입력창·표준 `Button`을 `TormiaMain`에 저장 |
| 이전 요소 제거 | 가입과 무관한 외형 버튼이 남아 있지 않음 | `CustomizeAppearanceButton` 제거 확인 |
| 회귀 | 기존 온톨로지 테스트와 개발 하네스가 정상임 | EditMode 53/53, World Authority Docker 빌드를 포함한 `verify-development.ps1` 통과 |

## 성능과 권한 영향

표현 계층만 변경했습니다. polling, 영속 월드 이벤트, DB 쓰기, 실시간 통신,
Authority 규칙에는 영향이 없습니다.
