# 순서가 보장되는 원격 아바타 이동 전송

## 결정

최신 위치를 빠르게 추격하는 방식을 Authority 시간 기반 원격 스냅샷 스트림으로
교체한다. 서버는 변경된 플레이어 상태를 정렬된 Zone 모션 프레임으로 보내고,
클라이언트는 이를 버퍼링하고 보간한다. HTTP는 복구 전용으로 유지한다.

## 경계

- Authority 고정 Tick 이동만 공유 위치의 소유자다.
- SignalR은 평가된 일시적 결과만 전송하며 작성된 Fact를 만들지 않는다.
- Unity는 오래된 세션/Tick을 거절하고 목적지를 예측하지 않는다.
- 변경분 프레임 누락으로 아바타를 제거하지 않으며 전체 복구 스냅샷이 존재 상태를
  조정한다.

## 증거

- 서버 Docker publish 성공.
- 플레이어 이동 및 모션 프레임 정책 테스트 통과.
- Unity Console에 새 컴파일 오류가 없으며 원격 버퍼 테스트가 순서, 보간, 제한
  외삽, 세션 변경, 긴 단절을 검증한다.
