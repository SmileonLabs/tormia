## 의도

계정 진입, 재사용 카탈로그, 기본 퀘스트, 전투 안내, 동적 온톨로지 요약이
번역된 온톨로지 ID를 저장하지 않으면서 일관되게 언어를 전환하도록 합니다.

## 결정과 경계

기본 사용자용 번역은 CSV 언어팩이 소유합니다. 작업 흐름 컴포넌트는 언어팩
키와 인자를 전달하며 Authority·전송 원시 상태는 진단 정보로만 남깁니다.
canonical 온톨로지 ID와 계정·월드 데이터는 번역하지 않습니다. 사용자 자유 입력
이름과 문장은 명시적인 키가 없는 한 원문을 유지합니다.

## 온톨로지 표현

게임플레이 의미는 바뀌지 않습니다. canonical 규칙, 프로필, 개념, 관계, 배치
정의, 캐릭터 템플릿, 파츠 ID는 표시할 때만 번역합니다.

## 검증

| 경우 | 기대 결과 | 증거 |
| --- | --- | --- |
| 활성화 / 추가 | 계정 상태·카탈로그·퀘스트·전투·동적 요약이 영문과 한글로 표시됨 | `OntologyLanguagePackServiceTests`, 프로젝트 커버리지 검증기 |
| 비활성화 / 제거 | 누락 키와 원시 사용자용 상태 대입을 검출함 | 소스 경계 및 커버리지 검사 |
| 회귀 / 예외 | 사용자 작성 문장은 원문을 유지하고 canonical ID는 바뀌지 않음 | 기본 퀘스트 fallback 및 canonical 해석 테스트 |

## 성능과 멀티플레이 영향

UI 갱신과 상태 변경 경계에서만 번역합니다. 새 polling, Authority 명령, 영속
쓰기, 네트워크 fan-out은 없습니다.
