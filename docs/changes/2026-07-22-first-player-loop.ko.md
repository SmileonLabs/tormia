# 첫 개발 플레이어 루프

- **날짜:** 2026-07-22
- **상태:** 개발용 Authority 흐름에 구현.

## 결정

첫 플레이 가능한 개발 여정은 신원과 월드 소유권을 분리합니다. 개발 신원은 휴대 가능한 기본 캐릭터 하나를 만들 수 있으며, 선택한 파츠는 계정 데이터로 남습니다. 첫 월드 입장 시 안정적인 로컬 Avatar GUID가 아직 Authority 월드 엔터티로 없을 때만 배치하고, 인증된 사용자에게 등록한 뒤 캐릭터 입장을 진행합니다.

개발용 `social_village` 패키지는 불변 `help`, `talk` 액션 정의를 발행하고 선택된 월드에서 해당 버전을 활성화합니다. Authority 연결이 활성화되어 있으면 퀘스트/액션 UI는 로컬의 영속 행동 결과 대신 `execute_action` intent를 보냅니다.

## 검증 기대값

- 선택된 캐릭터가 없는 연결 계정은 월드 입장 전에 휴대 가능한 기본 캐릭터를 만든다.
- 없는 Avatar 엔터티는 한 번 배치·등록되고, 이후 입장은 같은 안정 GUID를 사용한다.
- 공유 월드 액션에 Authority 엔터티나 패키지 정의가 없으면 눈에 보이게 거부하며 로컬 액션으로 되돌아가지 않는다.
