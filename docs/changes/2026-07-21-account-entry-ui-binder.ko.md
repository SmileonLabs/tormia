# 계정 진입 UI 바인더 검증

## 결정

- 계정·캐릭터·월드 진입 UI는 `TormiaMain` 하이라키가 소유한다.
- 바인더는 하이라키에 작성된 TMP/버튼을 연결하며 런타임에 UI를 새로 만들거나
  레이아웃을 임의로 결정하지 않는다.
- 계정 프로필(외형 파츠)은 월드 Fact가 아니며, 월드 입장 성공 후 캐릭터에 투영한다.

## 검증 결과

- 로컬 World Authority 계정 API: 통과(계정 1개, 캐릭터 1개, 월드 1개).
- 월드 입장: 통과(플레이어 아바타 등록 및 캐릭터 입장 승인).
- 명령 멱등성: 통과(같은 commandId 재전송 시 같은 revision을 반환).
- Docker PostgreSQL·Redis·World Authority 상태/health: 통과.
- 계정 진입 Unity 스모크: 통과.
- Unity Console: 이번 변경으로 새 오류·경고 없음.
- Unity Play Mode: 개발 계정 자동 연결, 저장된 캐릭터·월드 로드, 월드 입장,
  스냅샷 저장을 확인.

전체 EditMode 테스트에는 캐릭터 파츠 어댑터와 배치 오브젝트 의미 검증 관련
기존 실패 5건이 남아 있다. 이번 계정 진입 UI 컴파일 오류는 수정했고, 현재
Unity Console에는 컴파일 오류가 없다.

## UI 검증

`TormiaMain` 하이라키의 계정 진입 패널에서 상태 영역 높이와 버튼 위치를
조정했다. 계정·외형·플레이어 온톨로지 요약이 ENTER/CLOSE 버튼과 겹치지 않는다.
로컬 계정/캐릭터/월드 선택, 입장, 스냅샷 저장 및 다음 Play Mode에서의
스냅샷 불러오기를 검증했다. 운영 로그인만 별도의 인증 제공자 연동으로 남는다.
