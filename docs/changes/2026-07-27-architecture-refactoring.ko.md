## 결정

- 734개 항목의 작업 트리를 보존하고, 정리 편의를 위해 서드파티 하이라키나
  관련 없는 사용자 에셋을 덮어쓰지 않았습니다.
- 이름 기반 런타임 UI 탐색을 명시적인 씬/컴포넌트 연결로 교체했습니다.
- 계정 캐릭터 프리뷰의 중복 외형 구현을 제거했습니다.
- 안정 ID 기반 배치 오브젝트 Fact 투영과 예전 Subject 마이그레이션을
  별도 모듈로 추출했습니다.
- 제작 경로 계산과 타입 검증 오류를 UI에서 분리했습니다.
- 로컬 Authority 세션/선택 저장을 HTTP 클라이언트에서 분리했습니다.
- 외형 지연 저장은 캐릭터 단위로 캡처하고, 체크포인트 재시도는 리비전
  충돌로 제한하며, 원자적 파일 교체 구현을 공유합니다.
- 중첩된 Unity 프로젝트의 모든 에셋이 루트 프로젝트에 이미 존재함을
  확인한 뒤 오래된 복제본을 제거했습니다. 스크린샷, 복구 출력,
  이미지 생성 임시 파일과 향후 중첩 복제본은 디자이너 작업 증거를
  삭제하지 않고 Git 추적에서 제외합니다.
- 캐릭터 생성 프리뷰 복제본을 표현 전용으로 정리했습니다. Presenter가
  복제본을 명시적으로 소유하고, 복제된 게임플레이 어댑터 실행은
  비활성화하며, 오브젝트 이름 검색 없이 선택 아바타의 렌더러 상태를
  동기화합니다.

## 활성화 및 제거 경우

| 영역 | 활성화 경우 | 제거·비활성 경우 |
| --- | --- | --- |
| 런타임 UI | 명시 루트와 컴포넌트가 `InWorld`를 따름 | UI 이름 변경으로 게이트를 우회하지 않음 |
| 외형 | 공용 투영기가 연결 파츠와 변형을 적용 | 계정 프리뷰의 중복 구현 제거 |
| 외형 프리뷰 | Presenter 소유 렌더 복제본이 메시·재질 변경을 따름 | 복제된 게임플레이 어댑터가 두 번째 기본 외형 파이프라인을 실행하지 않음 |
| 배치 엔티티 | 안정 `entityId`가 영속 Fact를 소유 | 수정 가능한 인스턴스 이름은 새 Subject가 되지 않음 |
| 제작 Draft | 카탈로그가 결정적인 경로 하나를 생성 | 중복 서비스 ID와 최초 요청 서비스 누락 거부 |
| 외형 저장 | 캡처한 캐릭터와 파츠를 함께 저장 | 선택 변경이 보류 저장 대상을 바꾸지 않음 |
| 체크포인트 | `stale_revision`만 다시 읽고 재시도 | 권한·검증·전송 실패는 재시도하지 않음 |

- 관련 Unity, UI, Editor, Unity 테스트 어셈블리는 오류 없이
  컴파일됐습니다.

  실행해 모두 통과, 실패 0개, 건너뜀 0개를 확인했습니다.

  -RunAccountWorldLoopSmoke`가 World Authority 빌드와
  PostgreSQL·Redis·Authority 상태 검사를 포함해 통과했습니다.

  자동 저장, 로그아웃, 재로그인, 이어하기를 통과했습니다.
- 안정 배치 Fact Subject, 예전 Subject 마이그레이션, 세션 키 격리,
  중복 제작 서비스, 체크포인트 재시도 정책 테스트를 추가했습니다.
