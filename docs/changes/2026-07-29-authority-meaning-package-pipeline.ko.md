# Authority 소유 의미 패키지 파이프라인

## 요약

- **날짜:** 2026-07-29
- **상태:** 구현 및 검증 완료
- **요청:** 초기 템플릿 기본값에 제한하지 않고 사용자가 어떤
  오브젝트든 완전한 온톨로지 의미를 변경할 수 있게 한다.

## 의도

초기 카탈로그 트리플은 수정 가능한 기준값이며 고정된 오브젝트 타입이
아닙니다. 완전한 의미 패키지를 적용하면 튜브가 가라앉거나 바위가 뜰
수 있습니다.

## 데이터 분류

- 영속 월드 데이터: 작성 트리플, 룰블록 바인딩, 의미 패키지 기여 원장,
  밀려난 작성 기준값
- 추론 상태: 평가된 `Floating` 등의 `physical_state`
- Unity 표현: 승인된 투영에서 동기화되는 Rigidbody·부력·부착 어댑터

## 결정과 경계

`apply_meaning_package`는 리비전 기반 멱등 World Authority 명령입니다.
모든 트리플과 게시된 룰블록을 변경 전에 검증하고 하나의 PostgreSQL
트랜잭션으로 확정합니다. 엔티티의 명시적 의미 슬롯마다 하나의 활성
패키지가 존재하며, 교체할 때는 같은 리비전 안에서 이전 기여분의
기준값을 복원한 뒤 새 패키지를 적용합니다.

명령에는 템플릿·프리팹·메시·오브젝트 이름 제한이 없습니다. 패키지가
소유한 룰블록을 제거해도 전체 패키지 기여분이 함께 제거됩니다. Unity는
연결된 의미 데이터를 먼저 낙관적으로 변경하지 않습니다.

영속 브리지는 additive 월드 씬보다 먼저 활성화될 수 있습니다. 이후
편집 컨트롤러를 발견할 때마다 의존성 탐색과 이벤트 구독을 멱등하게
복구합니다. 따라서 UI에서만 바뀐 룰블록·의미 패키지가 다음 Authority
투영에 의해 원복되는 상태를 허용하지 않습니다.

## 검증

| 경우 | 기대 결과 | 증거 |
| --- | --- | --- |
| 활성 | 임의 외형 오브젝트가 `HeavySinking`에서 `LightBuoyant`로 바뀌고 `FloatableObject`와 게시 룰블록을 얻음 | `scripts/run-meaning-package-authority-smoke.ps1` |
| 제거 | 패키지 기여 트리플·룰을 철회하고 `HeavySinking` 기준값을 복원 | 같은 스모크 |
| 룰 제거 | 패키지 소유 룰블록 제거 시 전체 패키지를 제거하고 기준값 복원 | 같은 스모크 |
| 거절 | 잘못된 트리플·룰 패키지는 변경 전에 전체 거절 | `MeaningPackageContractTests` |
| Unity 투영 | 명령 우선 요청은 Authority 투영 전 로컬 온톨로지를 변경하지 않음 | `AuthorityMeaningPackageRequestIsCompleteAndDoesNotMutateLocally` |
| 늦은 월드 씬 | 브리지보다 늦게 생성된 편집 컨트롤러를 정확히 한 번 구독 | `AuthorityBridgeSubscribesWhenWorldEditorAppearsAfterBridgeEnable` |

## 성능·멀티플레이 영향

사용자 작업 한 번은 월드 리비전과 이벤트를 하나씩만 생성하며 프레임별
쓰기를 추가하지 않습니다. 교체와 복원은 기존 월드 트랜잭션 잠금 안에서
처리되고, Unity는 투영에서 실제 변경된 엔티티의 어댑터만 다시
동기화합니다.
