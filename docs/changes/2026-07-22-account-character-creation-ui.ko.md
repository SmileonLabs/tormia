# 계정 캐릭터 생성 UI

## 결정

개발용 계정 흐름에서 계정 캐릭터가 없으면 씬에 미리 배치된 캐릭터 생성 화면을 연다. 화면은 표시 이름, 현재 지원하는 `player` 템플릿, 계정 소유 착용 파츠를 `OntologyWorldAuthorityAccountEntryFlow`를 통해 전송한다.

## 경계

- 캐릭터 이름, 템플릿, 외형은 계정 프로필 데이터로 유지한다.
- 캐릭터 생성은 공유 월드 Fact를 기록하지 않는다.
- `TormiaMain` 씬이 uGUI 하이라키와 배치를 소유하고, 런타임 바인더는 미리 만든 컨트롤과 동작만 연결한다.
- 실시간 미리보기 카메라는 파츠 어댑터가 변경한 동일 캐릭터를 보여 주는 표현 계층이며 게임 규칙이나 Fact를 소유하지 않는다.

## 구현 결과

- `AccountCharacterCreationPanel`과 `AccountCharacterAppearancePanel`을 하나의 Farm UI 캐릭터 스튜디오처럼 구성했다.
- 스타일 카테고리, 파츠 카드, 중앙 착용 미리보기, 선택 파츠 상세, 캐릭터 이름, 뒤로/생성 버튼을 모두 하이라키에서 직접 후보정할 수 있다.
- 파츠 섬네일을 누르면 `OntologyCharacterPartAdapter`를 통해 즉시 장착/해제되며, 생성되는 계정 프로필에는 canonical 파츠 ID가 저장된다. 어댑터가 해제를 허용하지 않는 파츠는 장착 상태를 유지하고 어댑터 실패 사유를 표시하며, UI에 숨은 대체 동작을 두지 않는다.
- Edit Mode에서는 더미 카테고리·파츠 카드·마네킹으로 실제 배치와 크기를 확인할 수 있고, 런타임에서는 자동으로 숨긴다.
- 한글·영문 언어팩에 캐릭터 생성 스튜디오 문구를 함께 추가했다.

## 검증

- 임포트 후 Unity Console 신규 오류가 0건임을 확인했다.
- `Part_Hairstyle_Base`를 `Part_Hairstyle_Male_005`로 교체했을 때 중앙 캐릭터가 즉시 갱신되는 것을 확인했다.
- `TormiaMain` 씬에 편집 가능한 캐릭터 생성 하이라키와 실시간 미리보기 카메라를 저장했다.
- 확정된 캐릭터 스타일 카테고리 아이콘 13개를 투명 배경 256×256 PNG로 분리해 `Assets/Art/UI/CharacterCategoryIcons`에 저장했다.
- `CharacterCategoryIconSet`이 canonical 슬롯 ID와 표현용 스프라이트를 연결한다. 매핑을 제거하거나 누락해도 해당 아이콘만 숨겨지고 현지화된 텍스트 카테고리는 계속 사용할 수 있다.
- PlayMode에서 세로 스크롤되는 카테고리 버튼 13개가 생성되고, 맨 아래 `Accessory`까지 13개 모두 올바른 스프라이트를 받는 것을 확인했다.
- 카테고리 메뉴는 가운데 정렬된 큰 원형 아이콘만 보이도록 변경했다. 사각형 버튼 배경은 투명하고, 아이콘이 있으면 글자를 숨기며, 아이콘 누락 시에만 다국어 글자가 대체 표시된다.
- 확정한 플랫 캐릭터 생성 시안을 배경 이미지가 아닌 편집 가능한 uGUI 하이라키 오브젝트로 적용했다. 헤더, 카테고리 메뉴, 파츠 목록, 실시간 미리보기, 선택 외형 카드, 이름 입력, 하단 버튼은 기존 런타임 연결을 그대로 유지한다.
- `Assets/Art/UI/CharacterCreationFlat`의 프로젝트 소유 슬라이스 스프라이트가 캔버스, 패널, 미리보기 프레임, 입력창, 버튼, 선택 테두리, 스크롤바의 표현을 담당한다. 이 표현 자산을 제거해도 계정 프로필과 온톨로지 동작에는 숨은 대체 구현이 남지 않는다.
- 파츠 카드는 글자 없이 원형 마스크된 아이콘 섬네일만 표시한다. 카테고리와 파츠 목록의 세로 스크롤 동작은 유지하고, 보이는 스크롤바 오브젝트와 연결만 비활성화했다.
- 실시간 캐릭터는 이전 화면상 크기의 70%로 보이도록 구도를 조정하고 렌더 텍스처 비율을 유지한다. 월드 배경은 표현 전용 미리보기 카메라에서 분리했다.
- 런타임에서 같은 파츠 섬네일 버튼으로 `Part_Hairstyle_Base`가 장착 → 해제 → 재장착되는 것을 확인했다. `OntologyCharacterPartAdapterTests` 5개가 통과했고, Unity Console 오류 0건과 `scripts/verify-development.ps1` 통과를 확인했다.
- 섬네일 마스크와 선택 테두리는 Unity 기본 저해상도 Knob 대신 프로젝트 소유 256×256 안티앨리어싱 원형 스프라이트를 사용한다. 파츠 그리드는 144×144 셀과 6픽셀 간격으로 축소했다.
- 캐릭터 생성 합성 패널은 외형·계정 오버레이 사이의 기존 상대 위치를 유지하면서 화면 정중앙에 배치했다. Back/Create는 일반 Unity `Button`과 중앙 Stretch 앵커 글자를 사용해, 상태 변경 때 글자 Y를 8로 되돌리던 Farm UI `CustomButton` 동작을 제거했다.
- 두 캐릭터 생성 루트는 하이라키 오브젝트 108개/컴포넌트 354개에서 76개/237개로 정리했다. 아이콘 카드에서 사용하지 않는 글자 노드, 숨긴 구형 스크롤바 트리, 비활성 구조용 그래픽, 레거시 루트·커스터마이즈 버튼만 제거했으며 입력·이동·스크롤·마스크·미리보기 렌더링·온톨로지 어댑터는 유지한다.
