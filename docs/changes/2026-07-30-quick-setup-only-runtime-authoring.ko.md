# 빠른 설정을 사용자용 유일한 행동 저작 경로로 사용

## 요약

- **날짜:** 2026-07-30
- **상태:** 구현 및 검증
- **범위:** 런타임 온톨로지 편집기, 의미 패키지 저작, 하네스 정책

## 의도

사용자가 행동에 필요한 트리플과 선택적 물리 의미 계약을 준비하지 않은 채
규칙 블록만 연결하여 불완전한 상태를 만들지 않도록 합니다.

## 결정과 경계

- 규칙 블록 화면에는 `RuleBlockPresetDatabase`를 사용하는 하나의 빠른 설정
  선택기만 제공합니다.
- 프리셋은 선언된 개념, 작성 Fact, 규칙 블록, 선택적 물리 의미를 하나의
  Authority 소유 의미 패키지로 요청합니다.
- 연결된 규칙 블록은 계속 확인하고 제거할 수 있지만, 런타임 UI에서는
  규칙만 추가하거나 교체하는 기능을 제공하지 않습니다.
- 내부 컨트롤러 메서드는 완전한 프리셋/패키지를 조립할 때 바인딩을 구성할 수
  있지만 사용자용 fallback으로 사용하지 않습니다.
- 새로운 빠른 설정은 데이터로 추가합니다. Unity UI 코드에서 프리셋,
  프리팹, 메시, 엔티티 이름별 분기를 만들지 않습니다.

## 검증

| 경우 | 기대 결과 | 증거 |
| --- | --- | --- |
| 활성 | 하이라키에 배치된 하나의 빠른 설정이 데이터 기반 완전한 의미 패키지를 적용합니다. | `RuleBlockPage_UsesQuickSetupAsItsOnlyAuthoringEntry`, Authority 의미 패키지 테스트 |
| 제거/비활성 | 규칙 블록만 추가하거나 수정하는 런타임 버튼이 없으며 기존 연결은 제거할 수 있습니다. | `RuleBlockPage_UsesQuickSetupAsItsOnlyAuthoringEntry`, 규칙 블록 제거 추론 테스트 |
| 실패 | 프리셋 선행조건이 없으면 로컬 의미를 임시 변경하지 않고 패키지를 거부합니다. | `AuthorityMeaningPackageRequestIsCompleteAndDoesNotMutateLocally` |

## 성능과 멀티플레이 영향

폴링이나 프레임별 작업을 추가하지 않습니다. 영속 변경은 계속 하나의
리비전 기반·멱등 World Authority 의미 패키지 명령으로 처리합니다.
