# 상용화 준비도 점검 기준선

## 범위

추가 콘텐츠를 만들기 전에 현재 Unity와 World Authority 경계를 점검했습니다.

## 확인된 안전한 경계

- 영속 월드 편집은 리비전과 idempotent 명령을 사용합니다.
- 런타임 이동 입력은 제한된 빈도로 전송되는 임시 데이터이며 프레임마다
  영속 Fact나 월드 이벤트를 만들지 않습니다.
- Zone 목록과 projection 갱신은 주기 기반이며 realtime 알림은 최적화 수단일
  뿐 원본이 아닙니다.
- 애니메이션·물리 어댑터는 온톨로지 상태 변화에 반응하며 오브젝트 이름으로
  숨은 규칙을 추가하지 않습니다.
- viewer 편집은 클라이언트에서 차단하고 서버에서도 거부합니다.

## 출시 전 남은 조건

1. 준비된 SDK/Docker 환경에서 실제 .NET 서버 빌드 실행
2. 동시 클라이언트 부하 테스트: 명령 충돌, Zone polling, 임시 입력 lease
3. 배치 오브젝트 1/20/100개와 원격 아바타 수별 Unity Profiler 기준선 기록
4. 출시 전 실제 인증, rate limit, 메트릭, 구조화 감사 로그, 백업, 배포
   비밀값 구성을 추가

이번 점검에서는 게임플레이 fallback을 추가하지 않았습니다. 위 항목은 출시
조건이며 온톨로지나 Authority 경계를 우회하기 위한 이유가 아닙니다.
