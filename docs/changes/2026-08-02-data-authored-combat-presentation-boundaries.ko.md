# 데이터 작성형 전투 표현 경계

## 요약

- 날짜: 2026-08-02
- 상태: 검증 완료
- 범위: Unity 표현 및 입력 경계

## 의도

전투 표현이 고정 키, 임의 Collider 순서, 고정 쿼리 용량 또는 무기 템플릿
ID에 의존하던 가정을 제거합니다.

## 소유권

- 장치 바인딩은 Input Action 자산이 소유하며 게임 규칙 권한은 소유하지
  않습니다.
- 작성된 충돌 트리플이 전투 쿼리 프록시 크기를 소유합니다.
- 할당된 규칙 블록과 World Authority가 장착 및 피해를 계속 소유합니다.
- 투영된 애니메이션 의도 Fact가 장착 이동 표현을 소유합니다.

## 검증

| 경우 | 기대 결과 |
| --- | --- |
| 완전한 프록시 트리플 | 쿼리 전용 캡슐 생성 |
| 프록시 트리플 누락/모호 | Damageable 표현 실패 폐쇄 |
| 접촉 빠른 버퍼 초과 | 누락 없이 전체 쿼리 재시도 |
| 장착 엔티티 idle/move 의도 투영 | 대응 의도 선택 |
| 의도 Fact 제거 | 카탈로그/템플릿 대체 경로 없음 |

증거: 개발 하네스 통과, 전투 집중 EditMode 테스트 55/55 통과, 의미
어댑터 집중 PlayMode 테스트 2/2 통과, 컴파일 및 테스트 후 Unity Console
오류 없음.
