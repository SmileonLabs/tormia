# Unity UDP 이동 송신 준비

## 결정

Unity HTTPS 티켓 클라이언트, 고정 UDP 부트스트랩, 인증 이동 송신기를 준비하되
어댑터는 비활성으로 두고 HTTP만 실제 게임 Writer로 유지한다.

## 안전 경계

- 입장은 컴포넌트 수명, 런타임 세션, 월드, 아바타, Zone에 결합한다.
- 늦은 응답, 비활성화, 시간 초과, 연결 해제는 작업을 무효화한다.
- 모든 중지 경로에서 보관한 바이트 배열 자격 증명을 지운다.
- UDP는 입력 의미, 게임 판정, 영속 상태를 소유하지 않는다.

## 검증

- Unity 새로고침 후 새로운 C# 컴파일 오류가 없음을 확인했다.
- 부트스트랩 형식, 잘못된 자격 증명 거절, 패킷 인증, HTTP 대체 경로 테스트를
  추가했다.
- 공식 Unity MCP 테스트 작업이 시작 전에 정지해 실행 통과로 보고하지 않는다.
  실제 실행은 13단계 플랫폼 검증의 필수 조건으로 유지한다.
