# 분리된 원격 멀티플레이 테스트 Authority

## 요약

- **날짜:** 2026-08-03
- **담당:** TOV 팀
- **상태:** 검증 완료
- **관련 요청:** 기존 서비스에 영향을 주지 않는 멀티플레이 테스트 서버 구축

## 의도

기존 PunkArena 서비스를 유지하면서 Android 멀티플레이를 검증할 수 있는 안전한
Authority 서버 주소를 제공한다.

## 결정과 경계

테스트 배포는 `tormia_test` 데이터베이스, `tormia_test_app` 계정,
`tormia-test-authority` 컨테이너, `tov-api.punkarena.app` 가상 호스트만
소유한다. 기존 서비스의 데이터베이스, 프로세스, 포트, 가상 호스트를 변경하거나
재사용하지 않는다. RDS 관리자 비밀번호는 초기 생성에만 사용하고 이후 제거한다.

## 온톨로지 표현

게임플레이 관계 변경은 없다. 배포된 World Authority가 작성된 트리플, 규칙 블록,
공유 결과, 런타임 세션 계약의 기준이며 Unity에는 공개 Authority 주소만 전달한다.

## 검증

| 경우 | 기대 결과 | 증거 |
| --- | --- | --- |
| 활성화 / 추가 | 분리된 API가 PostgreSQL과 Redis에 연결 | `/health`, `/health/realtime`, `/health/scheduler` 정상 |
| 비활성화 / 제거 | 기존 서비스가 독립적으로 유지 | 새 컨테이너는 `127.0.0.1:5272`에만 바인딩, 별도 Nginx 호스트 사용 |
| 회귀 / 예외 | 에디터 전환값을 끄면 로컬 Authority로 복귀하고 Android는 원격 유지 | 대상 Unity EditMode 주소 선택 테스트 통과 |
| 에디터 원격 개발 | 로컬 URL을 유지하면서 플레이 모드와 작성 도구가 원격 HTTPS 사용 | 설정 기반 주소 전환 활성화 및 테스트 |
| TLS 갱신 | 수동 Nginx 변경 없이 인증서 갱신 | Certbot 갱신 모의 실행 통과 |

## 성능과 멀티플레이 영향

기존 Redis 백플레인과 전용 PostgreSQL 계정을 사용한다. 프레임 단위 영속 저장
정책에는 변경이 없다.
