# 수정 가능한 TOV 로그인 UI

## 요약

- **날짜:** 2026-07-23
- **상태:** 구현 및 런타임 검증 완료
- **데이터 분류:** Unity 표현과 언어팩 표시 문구

## 의도

확정한 TOV 로그인 시안을 Unity 씬에 적용하되, 사용자가 하이라키에서 각 요소를
직접 선택하고 위치·크기·색상을 후보정할 수 있게 유지합니다.

## 결정과 경계

- `AccountLoginPanel`은 기존 인증 프레젠터를 그대로 사용하며 World Authority 로그인과 계정 생성 이동 계약은 바꾸지 않습니다.
- 로고, 파란 테두리, 금색 테두리, 카드 표면, 제목, 라벨, 입력창, 버튼 표면은 합쳐진 배경 이미지가 아니라 각각의 uGUI 오브젝트입니다.
- 배치는 씬이 소유합니다. 런타임 코드는 번역 문구와 상호작용 상태만 갱신하며 위치나 크기를 다시 만들거나 덮어쓰지 않습니다.
- 로그인과 계정 생성 정보는 계정 인증 데이터이며 온톨로지 Fact나 월드 데이터가 아닙니다.

## 검증

| 경우 | 기대 결과 | 증거 |
| --- | --- | --- |
| 활성화 | TOV 로고와 한국어 입력 항목이 로그인 카드에 표시됨 | `account_login_tov_editable_runtime.png` |
| 화면 이동 | 계정 만들기를 누르면 로그인은 닫히고 계정 생성 화면이 열림 | 런타임 결과 `login=0, creation=1`, 로그인 복귀 뒤 `1` |
| 후보정 가능 | 모든 디자인 요소를 하이라키에서 선택 가능 | `BrandFrameBlue`, `BrandFrameGold`, `CardSurface`, `TovLogo`, 입력 오브젝트와 표준 `Button` 확인 |
| 이전 요소 제거 | 로그인에 관계없는 표시 이름·외형 버튼이 남아 있지 않음 | `CustomizeAppearanceButton`, `DisplayNameInput` 제거 확인 |
| 회귀 | 기존 온톨로지 EditMode 테스트와 개발 하네스가 정상임 | EditMode 53/53, World Authority Docker 빌드를 포함한 `verify-development.ps1` 통과 |

## 성능과 권한 영향

표현 계층만 변경했습니다. polling, 월드 이벤트, DB 쓰기, 실시간 통신,
Authority 동작에는 영향이 없습니다.
