# 처치 상태의 영속 표현

## 요약

- 날짜: 2026-07-29
- 상태: 구현 및 검증
- 범위: Authority 소유 영속 전투 상태의 Unity 표현

## 문제

Authority에는 `is_alive=false`, `current_health=0`이 올바르게 유지됐지만,
일회성 죽음 클립이 끝나면 기본 Idle 자세로 돌아갔습니다. 실제로는 처치
상태라 추가 공격을 거부하면서 외형만 살아난 것처럼 보였습니다.

## 결정

- Projection의 처치 상태가 canonical 죽음 애니메이션 의도를 선택합니다.
- 일반 애니메이션 어댑터는 Projection이 처치를 해제하거나 엔티티를
  제거할 때까지 해당 의도를 영속 상태 표현으로 유지합니다.
- 검증된 클립 자체의 길이와 프레임 속도로 마지막 유지 자세를 정합니다.
- Animator 상태 이름, 프리팹, 몬스터 종류, 메시, 오브젝트 이름을
  사용하지 않습니다.
- 체력, 공격 대상 자격, 피해, 폐기는 계속 World Authority가 소유하며
  이번 변경은 표현만 소유합니다.

## 검증

- 런타임 확인: `is_alive=false`, `current_health=0`, 충돌 비활성,
  영속 `Death` 의도, `Die` 클립 마지막 프레임에서 재생 속도 0.
- `DefeatedStateKeepsItsPersistentDeathPresentation` 테스트로 클립 종료와
  이동 관측이 처치 자세를 해제하지 않으며, 일반 일회성 표현은 정상적으로
  기본 표현으로 복귀함을 검증했습니다.
